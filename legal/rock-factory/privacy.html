Política de Privacidad

Rock Factory · Última actualización: 11 de agosto de 2026

1. Alcance

Rock Factory ("la Aplicación") es la aplicación oficial registrada en TikTok for Developers, de uso privado y operada por el titular de los canales del proyecto. No tiene usuarios externos ni recopila datos de terceros.

2. Datos que se tratan

DatoOrigenFinalidadConservación
Nombre de usuario y avatar de TikTok Scope user.info.basic Mostrar en pantalla qué cuenta recibirá el contenido, antes de cada carga No se almacena; se consulta en cada operación
Token de acceso OAuth Autorización del titular Autenticar las llamadas a la API de TikTok Almacenado cifrado; se elimina al revocar el acceso
Metadatos del contenido subido Generados por la Aplicación Registrar estado de cada pieza y evitar cargas duplicadas Base de datos local del operador

3. Datos que NO se recopilan

  • No se accede a mensajes privados ni a comentarios.
  • No se recopilan datos de seguidores ni de otros usuarios de TikTok.
  • No se utilizan cookies de seguimiento ni analítica de terceros.
  • No se recopilan datos de menores de edad.

4. Compartición con terceros

No se venden, alquilan ni comparten datos con terceros. La única transmisión de datos se produce hacia las API oficiales de TikTok, necesaria para el funcionamiento de la Aplicación.

5. Seguridad

Las credenciales se almacenan en archivos con permisos restringidos en un servidor privado, fuera del control de versiones. El acceso al servidor está limitado al operador.

6. Revocación de acceso

El titular puede revocar la autorización en cualquier momento desde TikTok → Configuración → Seguridad → Administrar aplicaciones. Al revocarla, los tokens almacenados dejan de ser válidos y se eliminan.

7. Derechos

Al tratarse de una herramienta de uso propio, el titular de los datos y el operador son la misma persona. Cualquier solicitud relativa a datos personales puede dirigirse al contacto indicado abajo.
